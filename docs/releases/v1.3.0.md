## Что нового

Речка перешла на **GigaAM v4** — модель для распознавания русской и английской речи. Обработка по-прежнему выполняется на устройстве, без интернета. Речь разделяется на фрагменты с помощью Silero VAD; потоковый режим самой GigaAM v4 не используется.

## Обновление и установка

- **`rechka-full.apk`** содержит новую модель и устанавливает её автоматически после запуска приложения.
- **`rechka-light.apk`** меньше, но для перехода на v4 нужно самостоятельно скачать четыре файла из [релиза Phone Whisper](https://github.com/ivkiwi/phone-whisper/releases/tag/models-gigaam-v4) и выбрать папку с ними в Речке:
  - `gigaam_v4_e2e_rnnt_encoder_int8.onnx`
  - `gigaam_v4_e2e_rnnt_decoder.onnx`
  - `gigaam_v4_e2e_rnnt_joint.onnx`
  - `gigaam_v4_e2e_rnnt_tokens.txt`

Сохраните файлы в отдельную папку, не в корень «Загрузок». После проверки и копирования исходные файлы можно удалить. Приложение проверяет размеры и SHA-256 модели.

При обновлении настройки сохраняются, а прежняя модель v3 остаётся в хранилище до успешной установки v4. До установки новой модели распознавание недоступно. На время замены потребуется место для старой и новой моделей; для лёгкого APK — также для скачанных файлов.

Проверьте SHA-256 скачанного APK по файлу `SHA256SUMS.txt` в этом релизе. Подробности — в [README](https://github.com/dm1sh/rechka#установка-модели) и [истории изменений](https://github.com/dm1sh/rechka/blob/v1.3.0/CHANGELOG.md).
