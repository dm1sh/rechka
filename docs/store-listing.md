# Карточка приложения

Тексты для описания Речки в магазине приложений или на странице релиза.

## Краткое описание (до 80 символов)

```
Голосовой ввод на русском и английском. Работает без интернета.
```

## Полное описание (до 4000 символов)

```
Речка — голосовой ввод и расшифровка записей без интернета

Диктуйте сообщения, заметки, поисковые запросы и другой текст. Речка распознаёт русскую и английскую речь прямо на телефоне — без аккаунта и облака.

Три способа работы

• Плавающий микрофон поверх других приложений — нажмите кнопку и говорите; распознанный текст появится в активном поле.
• Голосовая клавиатура Android — диктуйте и редактируйте текст в привычном поле ввода.
• Расшифровка аудио и видео — откройте файл в Речке или отправьте его через «Поделиться». Длинные записи обрабатываются последовательно, а текст появляется по мере готовности фрагментов.

Без интернета и передачи голоса

Распознавание выполняется на устройстве. Приложение не запрашивает разрешение на доступ в интернет; звук не отправляется на сервер. Для работы с микрофоном требуется разрешение на запись, а для плавающей кнопки — сервис специальных возможностей Android.

Модель GigaAM v4

Речка использует GigaAM v4 для русского и английского языков. Результат зависит от качества записи и может содержать ошибки. Речь распознаётся по отдельным фрагментам; паузы помогают их разделять.

Полный APK содержит модель и устанавливает её автоматически. В лёгком APK четыре файла модели нужно отдельно скачать через браузер и выбрать их папку при настройке. При обновлении с предыдущей модели приложение подскажет, как установить новую.

Открытый исходный код

Код приложения опубликован на GitHub. Инструкции по установке, сборке и подробности об используемых компонентах доступны в репозитории.
```

## Заметки для модерации

- Описание не обещает безошибочное распознавание и не сравнивает качество с другими продуктами без измерений.
- GigaAM v4 — название модели Giga; конвертация Phone Whisper и лицензии компонентов указаны в приложении и репозитории.
- Модель скачивается через браузер только для лёгкого APK; само приложение не заявляет разрешение на доступ в интернет.
